Manual research and inference loops

Run 1–100 passes using a local Gentoo LLM. Select one public HTTPS page or paste readable source text. Every pass is checkpointed; jobs continue when the browser closes. Draft notes are unreviewed and are not added to approved knowledge or used to train model weights automatically.

Public HTTPS only. Logins, redirects, private networks, PDFs and JavaScript-only sites are not automatically accessible.
Search by a single keyword to locate a manual. Ready (unreviewed) and approved PDFs can both be analyzed as drafts. PDFs still queued for extraction cannot be analyzed yet.
Each inference pass processes every extracted section in the selected page range. For large manuals, 10–100 passes can require thousands of local model calls. Sections are checkpointed, cancellable and never auto-approved.
